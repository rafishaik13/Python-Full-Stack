Tuple in Python:

Definition:

A tuple is an ordered collection of elements in Python. Tuples are written using round brackets ( ).

* ()
* immutable
* allows duplication
* ordered
* indexed
* sliced
* heterogenous
* iterable

Example:

student = ("Ravi", 20, 85.5, True)
print(student)

Output:

('Ravi', 20, 85.5, True)
 
Operations on Tuple in Python:

A tuple is an ordered and immutable collection of elements. We can perform several operations on tuples, but we cannot modify their existing elements.

Example:

a = (10, 20, 30)
b = (40, 50, 60)

1. Concatenation +

Used to join two tuples.

a = (10, 20)
b = (30, 40)

print(a + b)

Output:

(10, 20, 30, 40)

2. Repetition *

Repeats the elements of a tuple.

a = (1, 2, 3)

print(a * 2)

Output:

(1, 2, 3, 1, 2, 3)

Tuple Methods

Tuples have only two main methods.

1. count()

Counts how many times an element occurs.

numbers = (10, 20, 10, 30, 10)

print(numbers.count(10))

Output:

3
2. index()

Returns the position of the first occurrence.

numbers = (10, 20, 30)

print(numbers.index(20))

Output:

1

# Functions of Tuple in Python

Tuple functions are **built-in Python functions** that can be used with tuples.

Let's take:

```python id="3b7x8q"
t = (10, 20, 30, 40, 20)
```

### 1. `len()`

Returns the **number of elements** in the tuple.

```python id="0v8y7p"
print(len(t))
```

Output:

```text id="zq4y5f"
5
```

---

### 2. `max()`

Returns the **largest element**.

```python id="4q1y7r"
print(max(t))
```

Output:

```text id="t3q0o4"
40
```

---

### 3. `min()`

Returns the **smallest element**.

```python id="w5x2mz"
print(min(t))
```

Output:

```text id="k6o4x1"
10
```

---

### 4. `sum()`

Returns the **sum of all elements**.

```python id="g1s8kc"
print(sum(t))
```

Output:

```text id="2t3m8n"
120
```

---

### 5. `sorted()`

Returns the tuple elements in **sorted order as a list**.

```python id="q2h6lm"
t = (40, 10, 30, 20)

print(sorted(t))
```

Output:

```text id="5qv1nz"
[10, 20, 30, 40]
```

**Important:** `sorted()` returns a **list**, not a tuple.

---

### 6. `tuple()`

Converts another iterable into a tuple.

```python id="j7s4pk"
numbers = [10, 20, 30]

t = tuple(numbers)

print(t)
```

Output:

```text id="5y0g5x"
(10, 20, 30)
```

---

### 7. `any()`

Returns `True` if **at least one element** is true.

```python id="v0x9pr"
t = (0, 0, 10)

print(any(t))
```

Output:

```text id="q1v5sj"
True
```

---

### 8. `all()`

Returns `True` if **all elements** are true.

```python id="5b7c2n"
t = (10, 20, 30)

print(all(t))
```

Output:

```text id="1y9x6a"
True
```

## Tuple Methods

Tuple has only **two main methods**:

### `count()`

Counts how many times a value occurs.

```python id="r9c3vd"
t = (10, 20, 10, 30)

print(t.count(10))
```

Output:

```text id="6g2k8m"
2
```

### `index()`

Returns the position of the first occurrence.

```python id="k8s2vw"
t = (10, 20, 30)

print(t.index(20))
```

Output:

```text id="c7n4qx"
1
```

## ⭐ Quick Revision

| Function   | Purpose            |
| ---------- | ------------------ |
| `len()`    | Number of elements |
| `max()`    | Largest element    |
| `min()`    | Smallest element   |
| `sum()`    | Sum of elements    |
| `sorted()` | Sorts elements     |
| `tuple()`  | Converts to tuple  |
| `any()`    | At least one true  |
