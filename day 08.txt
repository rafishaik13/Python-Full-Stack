1. `capitalize()`

Converts the **first character to uppercase**.

s = "python programming"
print(s.capitalize())

Output:

Python programming

2. `title()`

Converts the **first letter of every word to uppercase**.

s = "python programming"
print(s.title())

Output:

Python Programming

 3. `istitle()`

Checks whether the string is in **title case**.

s = "Python Programming"
print(s.istitle())

Output:

True

 4. `lower()`

Converts all characters to **lowercase**.

s = "PYTHON"
print(s.lower())

Output:

python

5. `upper()`

Converts all characters to **uppercase**.


s = "python"
print(s.upper())

Output:

PYTHON

6. `islower()`

Checks whether all alphabetic characters are **lowercase**.

s = "python"
print(s.islower())

Output:

True

7. `isupper()`

Checks whether all alphabetic characters are **uppercase**.


s = "PYTHON"
print(s.isupper())


Output:

True

8. `swapcase()`

Converts uppercase to lowercase and lowercase to uppercase.

s = "PyThOn"
print(s.swapcase())

Output:


pYtHoN

9. `startswith()`

Checks whether a string **starts with** a particular value.


s = "Python"
print(s.startswith("Py"))

Output:

True

10. `endswith()`

Checks whether a string **ends with** a particular value.

s = "Python"
print(s.endswith("on"))

Output:


True

11. `strip()`, `rstrip()`, `lstrip()`

**`strip()`** removes spaces from both sides.

s = "  Python  "
print(s.strip())


Output:

Python

**`lstrip()`** removes spaces from the left side.


s = "  Python"
print(s.lstrip())

**`rstrip()`** removes spaces from the right side.

s = "Python  "
print(s.rstrip())

12. `count()`

Counts how many times a value occurs.

s = "banana"
print(s.count("a"))

Output:

3

13. `index()`

Returns the position of the first occurrence.

s = "Python"
print(s.index("t"))

Output:

2

⚠️ If the value is not found, `index()` gives an error.

21. `split()` and `rsplit()`

**`split()`** divides a string into a list.

s = "apple banana mango"
print(s.split())

Output:

['apple', 'banana', 'mango']

**`rsplit()`** also splits the string, but starts splitting from the **right side**.

s = "apple-banana-mango"
print(s.rsplit("-", 1))

Output:

['apple-banana', 'mango']
```
22. `join()`

Joins multiple strings together.

words = ["Python", "is", "easy"]

print(" ".join(words))

Output:

Python is easy

Another example:


words = ["A", "B", "C"]

print("-".join(words))

Output:


A-B-C

23. `center()`

Places a string in the **center** within a specified width.


s = "Python"
print(s.center(10, "*"))

Output:

**Python**

A list is a collection of elements in Python. It is used to store multiple values in a single variable.

A list is written using square brackets [ ].

Example:
numbers = [10, 20, 30, 40]

 Operations on List in Python:

List operations are actions performed on lists, such as adding, removing, accessing, joining, and checking elements

a = [10, 20, 30]
b = [40, 50, 60]

1. Concatenation (+)

Used to join two lists.

print(a + b)

Output:

[10, 20, 30, 40, 50, 60]

2. Repetition (*)

Repeats a list multiple times.

a = [1, 2, 3]

print(a * 2)

Output:

[1, 2, 3, 1, 2, 3]

3. Indexing

Used to access an element using its position.

print(a[0])
print(a[2])

Output:

10
30

4. Slicing

Used to get a part of a list.

a = [10, 20, 30, 40, 50]

print(a[1:4])

5. Membership (in)

Checks whether an element exists in the list.

a = [10, 20, 30]

print(20 in a)

Output:

True
not in
print(50 not in a)

Output:

True

List Functions in Python:

List functions are built-in Python functions that can be used with lists.

a = [10, 20, 30, 40]

1. len()

Returns the number of elements in the list.

print(len(a))

Output:

4

2. max()

Returns the largest element.

print(max(a))

Output:

40

3. min()

Returns the smallest element.

print(min(a))

Output:

10

4. sum()

Returns the sum of all elements.

print(sum(a))

Output:

100

5. sorted()

Returns a sorted list.

a = [30, 10, 40, 20]

print(sorted(a))

Output:

[10, 20, 30, 40]

6. list()

Converts another iterable into a list.

x = "ABC"

print(list(x))

Output:

['A', 'B', 'C']

7. any()

Returns True if at least one element is true.

a = [0, 0, 10]

print(any(a))

Output:

True

8. all()

Returns True if all elements are true.

a = [10, 20, 30]

print(all(a))

Output:

True

List Methods in Python

List methods are built-in methods used to add, remove, modify, and organize elements in a list.

Example:

numbers = [10, 20, 30, 20]
Important List Methods

1. append()

Adds an element at the end of the list.

numbers.append(40)
print(numbers)

Output:

[10, 20, 30, 20, 40]

2. insert()

Adds an element at a specific position.

numbers.insert(1, 15)
print(numbers)

Output:

[10, 15, 20, 30, 20]

3. extend()

Adds multiple elements to the end of a list.

numbers.extend([40, 50])
print(numbers)

Output:

[10, 20, 30, 20, 40, 50]

4. remove()

Removes the first occurrence of a specified value.

numbers.remove(20)
print(numbers)

Output:

[10, 30, 20]

5. pop()

Removes and returns an element using its index.

numbers = [10, 20, 30]

numbers.pop(1)
print(numbers)

Output:

[10, 30]

If no index is given, it removes the last element:

numbers.pop()

6. clear()

Removes all elements from the list.

numbers = [10, 20, 30]

numbers.clear()
print(numbers)

Output:

[]

7. index()

Returns the index of the first occurrence of a value.

numbers = [10, 20, 30, 20]

print(numbers.index(20))

Output:

1

8. count()

Counts how many times a value occurs.

numbers = [10, 20, 30, 20]

print(numbers.count(20))

Output:

2
