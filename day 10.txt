Dictionary in Python:

A dictionary is a collection of data stored in key-value pairs.

Syntax:
dictionary = {
    "key1": "value1",
    "key2": "value2"
}
Example
student = {
    "name": "Ravi",
    "age": 20,
    "course": "Python"
}

print(student)

Output:

{'name': 'Ravi', 'age': 20, 'course': 'Python'}

Characteristics of Dictionary:
*Stores data in key-value pairs.
*Keys must be unique.
*Dictionaries are mutable.
*Values can be duplicated.
*Keys must be immutable/hashable, such as strings, numbers, or tuples.
*Dictionaries are ordered by insertion order in modern Python.

Operations on Dict:

1. Accessing Values

We can access a value using its key.

print(student["name"])
print(student["age"])

Output:

Ravi
20

Using get():

print(student.get("course"))

Output:

Python

2. Adding Elements

We can add a new key-value pair.

student["city"] = "Delhi"

print(student)

Output:

{'name': 'Ravi', 'age': 20, 'course': 'Python', 'city': 'Delhi'}

3. Updating Values

We can change the value of an existing key.

student["age"] = 21

print(student)

Output:

{'name': 'Ravi', 'age': 21, 'course': 'Python'}

4. Checking Membership:

The in operator checks whether a key exists.

student = {
    "name": "Ravi",
    "age": 20
}

print("name" in student)
print("city" in student)

Output:

True
False

Using not in:

print("city" not in student)

Output:

True

 Built-in Functions Used with Dictionary:

1. len()

Returns the number of key-value pairs.

print(len(student))

Output:

3
2. max()

Returns the maximum key.

d = {"a": 10, "b": 20, "c": 30}

print(max(d))

Output:

c

max() works on the dictionary's keys by default.

3. min()

Returns the minimum key.

d = {"a": 10, "b": 20, "c": 30}

print(min(d))

Output:

a
4. sum()

Returns the sum of the keys when the keys are numbers.

d = {10: "A", 20: "B", 30: "C"}

print(sum(d))

Output:

60
5. sorted()

Returns the keys in sorted order as a list.

d = {30: "C", 10: "A", 20: "B"}

print(sorted(d))

Output:

[10, 20, 30]
6. dict()

Creates or converts data into a dictionary.

d = dict(name="Ravi", age=20)

print(d)

Output:

{'name': 'Ravi', 'age': 20}
7. any()

Returns True if at least one key is true/non-zero.

d = {0: "A", 1: "B"}

print(any(d))

Output:

True
8. all()

Returns True if all keys are true/non-zero.

d = {1: "A", 2: "B"}

print(all(d))

Output:

True

 Dictionary Methods:

1. keys()

Returns all keys.

student = {"name": "Ravi", "age": 20}

print(student.keys())

Output:

dict_keys(['name', 'age'])
2. values()

Returns all values.

print(student.values())

Output:

dict_values(['Ravi', 20])
3. items()

Returns all key-value pairs.

print(student.items())

Output:

dict_items([('name', 'Ravi'), ('age', 20)])
4. get()

Returns the value associated with a key.

print(student.get("name"))

Output:

Ravi

If the key doesn't exist, get() returns None by default.

print(student.get("city"))

Output:

None
5. update()

Adds new items or updates existing items.

student.update({"age": 21, "city": "Delhi"})

print(student)

Output:

{'name': 'Ravi', 'age': 21, 'city': 'Delhi'}
6. pop()

Removes a specified key and returns its value.

student = {"name": "Ravi", "age": 20}

x = student.pop("age")

print(x)
print(student)

Output:

20
{'name': 'Ravi'}
7. popitem()

Removes and returns the last inserted key-value pair.

student = {
    "name": "Ravi",
    "age": 20,
    "city": "Delhi"
}

print(student.popitem())

Output:

('city', 'Delhi')
8. clear()

Removes all items from the dictionary.

student.clear()

print(student)

Output:

{}
9. copy()

Creates a copy of the dictionary.

student = {"name": "Ravi", "age": 20}

new_student = student.copy()

print(new_student)

Output:

{'name': 'Ravi', 'age': 20}
10. setdefault()

Returns the value of a key. If the key doesn't exist, it adds the key with the specified default value.

student = {"name": "Ravi", "age": 20}

student.setdefault("city", "Delhi")

print(student)

Output:

{'name': 'Ravi', 'age': 20, 'city': 'Delhi'}
