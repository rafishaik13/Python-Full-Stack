Tuple in Python:

Definition:

A tuple is an ordered collection of elements in Python. Tuples are written using round brackets ( ).

* ()
* immutable
* allows duplication
* ordered
* indexed
* sliced
* heterogenous
* iterable

Example:

student = ("Ravi", 20, 85.5, True)
print(student)

Output:

('Ravi', 20, 85.5, True)
 
Operations on Tuple in Python:

A tuple is an ordered and immutable collection of elements. We can perform several operations on tuples, but we cannot modify their existing elements.

Example:

a = (10, 20, 30)
b = (40, 50, 60)

1. Concatenation +

Used to join two tuples.

a = (10, 20)
b = (30, 40)

print(a + b)

Output:

(10, 20, 30, 40)

2. Repetition *

Repeats the elements of a tuple.

a = (1, 2, 3)

print(a * 2)

Output:

(1, 2, 3, 1, 2, 3)


3. Slicing

We can get a part of a tuple.

numbers = (10, 20, 30, 40, 50)

print(numbers[1:4])

Output:

(20, 30, 40)

4. Indexing

Indexing is used to access individual elements of a tuple.

t = (10, 20, 30, 40)

print(t[0])
print(t[2])
print(t[-1])

Output:

10
30
40

5. Membership Operation

The in and not in operators are used to check whether an element exists in a tuple.

t = (10, 20, 30, 40)

print(20 in t)
print(50 not in t)

Output:

True
True

Functions in Tuple in Python:

1. len()

Returns the number of elements in the tuple.

print(len(t))

Output:

5

2. max()

Returns the largest element.

print(max(t))

Output:

40

3. min()

Returns the smallest element.

print(min(t))

Output:

10

4. sum()

Returns the sum of all elements.

print(sum(t))

Output:

120

5. sorted()

Returns the tuple elements in sorted order as a list.

print(sorted(t))

Output:

[10, 20, 20, 30, 40]

6. tuple()

Converts another iterable, such as a list, into a tuple.

numbers = [10, 20, 30]

t = tuple(numbers)

print(t)

Output:

(10, 20, 30)

7. any()

Returns True if at least one element is true/non-zero.

t = (0, 0, 10, 0)

print(any(t))

Output:

True

8. all()

Returns True if all elements are true/non-zero.

t = (10, 20, 30)

print(all(t))

Output:

True

Methods in Tuple in Python:

A tuple has only two built-in methods because tuples are immutable.

1. count()

The count() method returns the number of times a particular element occurs in the tuple.

Syntax:

tuple.count(element)

Example:

t = (10, 20, 30, 20, 40)

print(t.count(20))

Output:

2

2. index()

The index() method returns the index position of the first occurrence of an element.

Syntax:

tuple.index(element)

Example:

t = (10, 20, 30, 20, 40)

print(t.index(20))

Output:

1

Set in Python

A set is an unordered, mutable collection of unique elements in Python. Sets are written using curly braces {}.

Example
s = {10, 20, 30, 40}
print(s)

Output:

{10, 20, 30, 40}

Note: Sets do not allow duplicate values.

s = {10, 20, 20, 30, 30}
print(s)

Output:

{10, 20, 30}

Characteristics of Set:

*Sets are unordered.
*Sets are mutable.
*Sets do not allow duplicates.
*Sets can contain different data types.
*Set elements must be immutable/hashable.
*Sets do not support indexing or slicing.

Operations on Set:

1. Union

Union combines all elements from two sets and removes duplicates.

Operator: |

A = {1, 2, 3}
B = {3, 4, 5}

print(A | B)

Output:

{1, 2, 3, 4, 5}

Using method:

print(A.union(B))

2. Intersection

Intersection returns the elements that are common to both sets.

Operator: &

A = {1, 2, 3}
B = {2, 3, 4}

print(A & B)

Output:

{2, 3}

Using method:

print(A.intersection(B))
3. Difference

Difference returns elements present in the first set but not in the second set.

Operator: -

A = {1, 2, 3}
B = {2, 3, 4}

print(A - B)

Output:

{1}
print(B - A)

Output:

{4}

Using method:

print(A.difference(B))

4. Symmetric Difference

Returns elements that are present in either set, but not in both.

Operator: ^

A = {1, 2, 3}
B = {2, 3, 4}

print(A ^ B)

Output:

{1, 4}

Using method:

print(A.symmetric_difference(B))

5. Membership Operation

The in operator checks whether an element exists in a set.

s = {10, 20, 30}

print(20 in s)
print(50 in s)

Output:

True
False

not in can also be used:

print(50 not in s)

Output:

True

Methods in Set in Python

A set has several built-in methods used to add, remove, and perform operations on elements.

Consider:

s = {10, 20, 30}

1. add()

Adds one element to the set.

s.add(40)
print(s)

Output:

{10, 20, 30, 40}

2. update()

Adds multiple elements to the set.

s.update([50, 60])
print(s)

Output:

{10, 20, 30, 50, 60}

3. remove()

Removes a specified element. It gives an error if the element doesn't exist.

s.remove(20)
print(s)

Output:

{10, 30}

4. discard()

Removes a specified element. It does not give an error if the element doesn't exist.

s.discard(30)
print(s)

Output:

{10}

5. pop()

Removes and returns an arbitrary element because sets are unordered.

s = {10, 20, 30}
x = s.pop()

print(x)
print(s)

The value removed can vary.

6. clear()

Removes all elements from the set.

s = {10, 20, 30}
s.clear()

print(s)

Output:

set()

7. copy()

Creates a copy of a set.

s = {10, 20, 30}
s2 = s.copy()

print(s2)

Output:

{10, 20, 30}

8. union()

Returns all elements from both sets.

A = {1, 2, 3}
B = {3, 4, 5}

print(A.union(B))

Output:

{1, 2, 3, 4, 5}

9. intersection()

Returns common elements.

A = {1, 2, 3}
B = {2, 3, 4}

print(A.intersection(B))

Output:

{2, 3}

10. difference()

Returns elements present in the first set but not the second.

A = {1, 2, 3}
B = {2, 3, 4}

print(A.difference(B))

Output:

{1}

11. symmetric_difference()

Returns elements that are present in either set but not in both.

A = {1, 2, 3}
B = {2, 3, 4}

print(A.symmetric_difference(B))

Output:

{1, 4}

12. issubset()

Checks whether one set is a subset of another.

A = {1, 2}
B = {1, 2, 3}

print(A.issubset(B))

Output:

True

13. issuperset()

Checks whether one set contains all elements of another set.

A = {1, 2, 3}
B = {1, 2}

print(A.issuperset(B))

Output:

True

14. isdisjoint()

Checks whether two sets have no common elements.

A = {1, 2}
B = {3, 4}

print(A.isdisjoint(B))

Output:

True
